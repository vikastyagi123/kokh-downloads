# Kokh — downloads

Public download host for the [Kokh](https://kokh.in) app. No source code lives
here, only release assets.

## Android

This link always resolves to the newest release, so it never needs updating:

```
https://github.com/vikastyagi123/kokh-downloads/releases/latest/download/kokh.apk
```

Most people should just open **<https://kokh.in/get>** on their phone instead —
it picks the right option for Android or iPhone automatically.

## iPhone

Apple does not allow installing apps from a link. Kokh runs through Expo Go
until it is on the App Store.
